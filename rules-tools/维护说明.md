# 校规随手查维护

页面：`rules.html`；首页入口及全站搜索：`index.html`。沿用 `campus-services.css`，页面专用样式为 `rules.css`。

`rules-assets/rules-data.json` 是唯一规则数据来源，包含全部页文本、134 个规则记录、中文说明、出处、条件提示和关联 ID。中文说明是参考摘要，英文原文及完整 PDF 供核对。`rules.js` 只渲染和管理界面；`rules-search.js` 负责同义词、英文词边界、编号检索、范围筛选及混合排序；`rules-semantic-worker.js` 在工作线程中编码查询和比较真实向量。

## 搜索部署

普通静态服务器或 GitHub Pages 的 HTTPS 环境即可，不需要后端、账户或 API 密钥。浏览器需要 Web Worker、WebAssembly 和访问模型下载站/CDN。网页本身、PDF 和数据均使用相对链接，已在 `/guidecat/` 子目录实际验证。

模型是 `Xenova/multilingual-e5-small`，固定 revision `761b726dd34fb83930e26aab4e9ac3899aa1fa78`。使用量化 ONNX、384 维、mean pooling、L2 normalize；条款使用 `passage: ` 前缀，查询使用 `query: ` 前缀。148 个跨页条款文本块构建时编码，浏览器只编码查询。索引记录数据 SHA-256，查询与索引维度及版本不符时降级，不能误报无规定。

运行库 `@xenova/transformers` 2.17.2 已随页面保存，约 898 KB，只在提交语义搜索时导入。ONNX 模型 118,308,185 字节，另外需要分词器和 WASM 运行文件，首次总下载量大于 118 MB，后续由浏览器资源缓存复用。未保存学生查询；进程内 Map 缓存随页面关闭消失。查询不发送给外部服务，外部请求仅下载模型/运行文件。模型加载失败、离线或索引失败时显示普通搜索降级；普通搜索未命中不会宣称资料中没有规则。

底模许可 MIT：[官方模型卡](https://huggingface.co/intfloat/multilingual-e5-small)。运行方案依据 [Transformers.js 官方文档](https://huggingface.co/docs/transformers.js/index)。实际模型版本及参数记录在 `rules-assets/rules-index.json`。

## 修改中文说明与重建索引

在项目根目录运行 PowerShell（路径含空格请保留引号）：

```powershell
$env:NODE_PATH='C:\Users\15319\.cache\codex-runtimes\codex-primary-runtime\dependencies\node\node_modules'
& 'D:\Program Files\nodejs\node.exe' rules-tools/reindex.cjs .
```

该命令使用本机已安装 Playwright 和 Chrome，编码全部规则块，重写 `rules-index.json` / `rules-vectors.bin`，保存真实语义回归分数到 `rules-tools/semantic-calibration.json`。先改 `summaryZh`、标题或原文，再重建索引；不要只改数据后继续使用旧向量。首次需要联网下载公开模型。修改纯同义词时不需要重新编码原文。

## 替换 PDF

1. 原样替换 `rules-assets/discipline.pdf`、`hostel.pdf` 或 `dress.pdf`，不要删页或重制。
2. 在项目根目录提取全部页面供重新核对：

```powershell
& 'C:\Users\15319\.cache\codex-runtimes\codex-primary-runtime\dependencies\python\python.exe' rules-tools/extract-pdfs.py
```

3. `rules-tools/extracted-pages.json` 是审核用提取结果，不会自动把新政策塞入网页。对照它更新 `rules-data.json` 中的 documents 全部页文本/页数/版本/哈希，以及 rules 的条款原文、页序、印刷页码、中文说明、对象、条件、例外、分类及关联 ID。编号发生变化时新增稳定 ID，并修正引用；没有依据就不补政策。
4. 用 Poppler 对图示页重新渲染，更新 `figureReferences` 及 figures；不要用 OCR 文字代替着装图示。当前附录是 PDF 第 20–26 页。
5. 重建索引；重新核对常见和陌生问法、罚款与期限、页面定位和故障降级。更新覆盖报告后发布。

浏览器语义检索并非任意表达都可靠。已校准的内部相似度阈值不是准确率，界面不展示分数。陌生表达可能产生宽泛结果，用户应核对原文；不要将命中或未命中当作学校批准。320–1440px 是浏览器视口测试，不代表所有真实手机型号已测。
